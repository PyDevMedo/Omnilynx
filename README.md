# Omnilynx

Professional Windows Customization & Modding Suite powered by a native C++ x64 Hook & Injection Engine.

## Features
- **Omnilynx Mod Control Center**: Illuminated power switches, bilingual UI (Arabic RTL & English LTR), and easy visual settings.
- **Windows Quick Tweaks**: Instant system-wide Windows 11/10 customization (Dark Mode, Transparency/Mica, Taskbar Alignment, Clock Seconds, File Extensions, Compact Explorer).
- **Explore Store & Live Preview**: Browse, preview README/options/source code, and install mods directly from `PyDevMedo/Omnilynx`.
- **Built-in C++ Code Editor**: Write, compile to native x64 DLLs (via Clang/MinGW), and inject/eject into processes.

## Development
```bash
npm install
npm run electron:start
```

## Build Windows Installer (`.exe`)
